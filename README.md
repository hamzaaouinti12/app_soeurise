# Projet Soeurise

Ce projet regroupe :
- Un backend **Node.js/Express** avec MongoDB.
- Un frontend **Flutter/Dart**.

## Prérequis
- Node.js installé
- Flutter SDK installé
- MongoDB en cours d'exécution sur le port 27017

## Démarrage rapide

Vous pouvez utiliser le script à la racine pour tout lancer :
```bash
./start.bat
```

Ou les lancer séparément :

### Backend
```bash
cd soeurise-backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
flutter pub get
flutter run -d windows
```
