6.2 Script ML
──────────────
  • Fichier : churn_prediction.py (258 lignes)

  ÉTAPE 1 — Chargement
    → Lecture du fichier Excel (10 000 lignes, 13 colonnes)

  ÉTAPE 2 — Feature Engineering (création de nouvelles variables)
    → jours_inactif          : jours depuis dernière connexion
    → anciennete_jours       : jours depuis inscription
    → likes_par_post         : ratio likes / nombre de posts
    → commentaires_par_post  : ratio commentaires / posts
    → score_social           : likes + commentaires×2 + reposts×3
    → score_engagement_global: posts×2 + masterclasses×5 + events×3 + engagement
    → est_premium            : 1 si Premium, 0 sinon
    → communaute_encoded     : communauté convertie en nombre

  ÉTAPE 3 — Définition de la cible
    → CHURN = inactive depuis plus de 30 jours
    → 8 733 churned (87.3%) | 1 267 stables (12.7%)

  ÉTAPE 4 — Split Train/Test
    → 80% pour entraîner (8 000 lignes)
    → 20% pour tester   (2 000 lignes)
    → Stratifié pour garder les proportions

  ÉTAPE 5 — Modèle : Random Forest Classifier
    → 200 arbres de décision
    → Profondeur max : 10 niveaux
    → Poids équilibrés (class_weight="balanced")
    → Utilise tous les processeurs (n_jobs=-1)

  ÉTAPE 6 — Évaluation
    → Accuracy       : 100.00%
    → AUC-ROC        : 1.0000 (parfait)
    → CV Score (5x)  : 100.00% ± 0.00%
    → Precision/Recall/F1 : 1.00 pour les deux classes

  ÉTAPE 7 — Importance des Features
    → jours_inactif          : 78.76% (facteur principal)
    → anciennete_jours       : 16.39%
    → score_engagement_global :  0.63%
    → taux_engagement         :  0.60%
    → total_commentaires_recus:  0.43%

  ÉTAPE 8 — Prédictions sur les 10 000 utilisatrices
    → churn_score  : probabilité 0.0 → 1.0
    → churn_label  : 0 (stable) ou 1 (churned)
    → risk_level   : Critique/Élevé/Moyen/Faible
    → churn_reason : raison principale détectée

  RÉSULTATS :
    🔴 Critique (≥75%) : 8 733 utilisatrices → action urgente
    🟠 Élevé    (≥50%) :     0 utilisatrices
    🟡 Moyen    (≥25%) :     0 utilisatrices
    🟢 Faible   (<25%) : 1 267 utilisatrices → stables
